Study Summary

These are the main technical themes found in the project code.

Architecture

Thin launcher, packaged backend

main.py only boots Uvicorn, start.py waits for /ping, and the real backend logic lives in the app/ package.

Data flow

Upload, extract, chunk, store, query

The ingestion path streams uploads to a temp file, extracts text with PyMuPDF or plain text readers, chunks content with overlap, and saves vectors in ChromaDB.

Generation

Chat, quiz, flashcards, code review

The backend feeds a selected document or full corpus context into Groq and expects structured JSON for the study features.

Safety

Hardening and cleanup

The code enforces a file size cap, sanitizes filenames, cleans up temp files, and optionally checks an API key and CORS allowlist.
