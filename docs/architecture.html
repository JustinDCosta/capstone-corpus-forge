Corpus Forge Architecture

A local RAG application built from a launcher, a FastAPI backend, a Streamlit frontend, and local persistence for vectors and artifacts.

Primary Sequence

This sequence covers the main launch path and the two most important user actions: uploading a document and asking a question.

sequenceDiagram participant U as "User" participant L as "start.py" participant B as "main.py / Uvicorn" participant F as "frontend.py / Streamlit" participant R as "app.routes" participant X as "app.utils" participant D as "ChromaDB" participant G as "Groq API" U->>L: "Run python start.py" L->>B: "Start backend process" loop "Poll /ping until ready" L->>B: "GET /ping" alt "Backend is not ready yet" B-->>L: "No response or non-200 status" else "Backend is ready" B-->>L: "200 OK" end end L->>F: "Start Streamlit frontend" U->>F: "Upload a file from the sidebar" F->>R: "POST /upload/" R->>R: "Validate filename, type, and size" alt "Upload accepted" R->>X: "extract_text_from_file()" X-->>R: "Raw text" R->>X: "chunk_text()" X-->>R: "Overlapping chunks" R->>D: "Replace any existing chunks for the same filename" D-->>R: "Chunks stored" R-->>F: "Upload success" F->>R: "GET /documents/" R-->>F: "Updated document list" else "Upload rejected" R-->>F: "HTTP error" end U->>F: "Submit a chat request" F->>R: "POST /chat/ with query and optional filename" R->>D: "collection.query()" D-->>R: "Top matching chunks" R->>G: "Generate answer from context" G-->>R: "Response and token usage" R-->>F: "Answer and metrics" F->>R: "GET /metrics/" R-->>F: "Latest counters"

Notes

  • main.py is only a thin Uvicorn entry point.
  • start.py is the convenience launcher that waits for /ping before opening the UI.
  • frontend.py uses HTTP requests only; it does not talk to ChromaDB or Groq directly.
  • app/routes.py owns request handling, while app/utils.py handles extraction and chunking.
  • data/artifacts/ stores generated quizzes and flashcards as JSON files.
  • chroma_db/ is the local persistent vector store used by the backend.

Assumptions

  • The project is run locally, matching the code’s localhost defaults.
  • Streamlit is the only frontend in the current workspace.
  • The backend may be launched either by start.py or directly with python main.py.
